# 上台演示顺序

先启动后端和前端，打开 http://127.0.0.1:5173 。账号使用已有项目管理员；本机预览账号保存在忽略目录 `.local/预览账号.txt`，不要放进PPT或GitHub。真实LLM需要本机.env与生效PricePlan，单用户每日预算CNY2。

1. **训练与数据**：先看2项已核验训练数据和5项尚缺文件；点“查看样例”只看脱敏有限行。展示BM25实际全量索引90,000行→61,987文档/切片，明确BGE/Milvus还待模型与服务实机联调。
2. **训练证据**：当前配置是linear/wd0/1epoch/关闭早停；选择 imported-cosine-history 展示36条真实历史日志、loss/LR曲线、epoch .96/48%提前停止。明确这不是线性日志，原始CSV是20候选池评测。当前候选adapter尚未被检索使用。
3. **协作问诊**：使用明确标注的合成病例：“27岁，咳嗽3天，无药物过敏史，没有胸痛或呼吸困难。”先看到补充用药/基础病史；填写“目前无用药、无基础疾病”，提交后看问诊→检索→风险与用药→辩论条件判断→解释→安全审核。回复只在审核后出现。临床体征未提供则显示信息不足，不能演示成低风险已确诊。
4. **证据与反馈**：查看发布回复中的引用；点击有帮助/需改进，可选择是否允许脱敏回流。授权默认关闭，可撤回。勾选是技术演示，不意味着人工相关性审校已通过。
5. **数据飞轮**：收集已授权反馈，选中待审候选。展示原始问题+补充信息、引用来源、人审正/负证据、冻结批次和训练准备入口。没有经过医学/检索相关性核对的真实候选保持待审；不要为了数字好看直接审批。隔离自动测试已经验证批次导出、撤回拦截、holdout隔离和显式难负例被训练Dataset消费。
6. **监控与账单**：展示真实Agent耗时、检索指标、失败分类、usage和成本；未接入和无命中分别解释。科普查询在新会话同用户重复可展示已审核缓存命中，第二次无新增模型token。
7. **急症分支**：另开会话输入合成案例“突发胸痛且呼吸困难”，展示立即急诊/120、停止常规检索。不要和普通咳嗽病例混在同一会话；前轮急症没有解除时系统会持续保留警报。

答辩用语：我们完成了可运行的Web、真实LLM审核链、训练观测和反馈训练准备；已验证BM25全量语料索引。BGE/Milvus全库召回、真实药物表、GPU新训练与完整容器部署分别列为待联调，不能宣称已完成。
