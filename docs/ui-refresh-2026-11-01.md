# 页面改版与本地复查（2026-11-01）

本说明记录本地审阅时的改版与验证。用户于 2026-11-01 审阅后授权提交 GitHub，最新提交范围见 [交付备注](releases/2026-11-01.md)。此次变更在上一轮 LLM + Web 实现之上进行，不代表整个系统已与同学的算法模块联调完成。

## 改版内容

参考淡水鱼与钢材项目的居中导航、主题背景、场景导览、浅色面板和真实指标布局，重新设计医疗平台。使用淡青、米白与少量金色，去掉旧侧栏，改为顶部品牌、五项居中导航和账号区。

- 工作台：医疗场景导览、模型配置与知识库状态、最近问诊、真实调用分布、反馈和协作流程。
- 问诊：保留会话历史、症状输入、协作进程、安全审核与引用入口，统一三栏面板风格。
- 智能体中心：各能力选择、管理员独立测试、最近运行记录；手机端能力列表允许横向滚动。
- 运行监控：真实调用、反馈与失败统计；检索与知识库未接入时继续显示“未接入”或“—”。
- 用量与账单：实际 usage、调用时价格快照、运行汇总与每日预算；区分今日和累计费用。
- 登录及各页：统一按钮、输入框、中文层级、留白和可读字号；每页使用对应的场景插画。

流程图明确标注“流程示意”，不会作为实时任务进度。首页“模型服务已配置”仅表示配置存在，不冒充模型健康探测。业务数值来自后端接口，没有写死成功率、成本、模型名称、预算或知识库规模。展示文案与导航集中在 `frontend/src/config/workspace.ts`，背景地址通过 `VITE_WORKSPACE_BACKGROUND_URL` 配置。

## 分工与兼容边界

本轮源代码变更限定在前端；另新增改版、CI 诊断和素材说明文档。未改同学的 Coordinator、基础四 Agent、RAG、Milvus 或 LoRA 代码。未变更后端接口、身份权限、发布护栏或结算逻辑。密钥继续只存本地 `.env`，未进入素材、截图或源码包。

医疗环境背景使用内置 image_gen 生成，页面插画使用代码绘制的 SVG；背景并非真实医疗机构照片。完整提示词、文件与校验值见 [素材来源](assets/medical-background.md)。原始大图作为独立审阅素材，仓库只放压缩后的 WebP。
