# v2 发布备注：训练观测、问诊流程与反馈飞轮

基于doctor-quest/main的c5fe06a开发；先交付源码、截图、完整测试记录和7份说明供本地审阅，用户随后明确授权直接上传main。无PR，无强制推送，不改变同学默认线性训练超参。

## 变更

- 新增训练与数据页面：声明规模/文件核验分开、受限脱敏样例、真实日志游标、loss/学习率曲线、训练阶段和模型版本审校/回滚。
- 安全导入用户ZIP：训练90,000/验证10,000行、余弦历史36条日志、epoch .96早停、实际1200/2500=48%；当前选型仍是linear/wd0/1epoch/关闭早停。最优checkpoint900缺失、checkpoint1200未绑定模型评测均如实显示。
- 问诊按急症预检、病史追问、检索、风险/用药并行、分歧条件判断、解释、审核后发布执行；持久化进度与WS事件恢复。上游实际意见不足时辩论显示已跳过。
- 补齐基础Agent、LangChain历史和RAG业务；实际BM25全量90,000行生成61,987文档/切片，去重28,013。增加真实BGE/LoRA、Milvus混合检索、RRF及Cross-encoder接入代码与版本门禁。
- 用药数据导入、别名映射、相互作用/过敏禁忌/特殊人群核查；NEWS2与原始Framingham公式、完整输入/适用人群校验。缺临床表与未校准概率不伪造结论，不自动发布个体剂量。
- 数据飞轮：默认关闭授权、撤回、脱敏、人审相关性与证据、查询去重/holdout隔离、冻结批次、BGE训练配置及显式难负例消费；网页不自动启动GPU训练。
- 统一usage计费与预算继续适用；新增仅同用户科普已审核回复缓存、原子token bucket、服务模式Redis会话及共享索引/交接卷。
- 修复同学4条训练提交中的13项Ruff错误，保留默认训练参数；没有通过跳过检查解决CI。
